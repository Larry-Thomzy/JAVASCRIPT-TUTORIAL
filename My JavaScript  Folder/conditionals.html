Javascript conditions

conditional statement allow our program to make decisions.
it checks if something is true or false, then runs the right code.
For Example: if it rains, i will take an umbrella, else i won't.

Switch Statement

A switch statement is used when you want to check one variable against multiple possible values
it works like multiple if...else, but it's easier and cleaner to read.

Ternary operator

Ternary operator is a short form of an if...else statement
It's called ternary because it takes 3 operands:

  • Condition → what you're checking (must be true or false)
  • expressionIftrue → what runs if the condition is true
  • expressionIffasle → what runs if the condition is false

condition → ? expressionIfTrue → : expressionIfFalse → ;
