🔃 Loop

A loop let's you run the same block of code multiple times until a condition is met

Types of loops in Javascript

  1. for loop → It is used when you know how many times you want to run the code.
  2. while loop → It runs as long as the condition is true.
  3. do..while loop → Similar to while loop, but it runs at least once, even if the condition is false
  4. for..of loop → Used arrays, strings etc.
  5. for..in loop → Used for objects
