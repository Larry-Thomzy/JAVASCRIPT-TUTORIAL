Truthy and Falsy Values

In Javascript, every value is considered Truthy (Evaluates to true) or Falsy (Evaluates to false) when used in a boolean context (Like inside if, while, logical operators, etc.).

Falsy values.

These are the values that evaluates the false in a boolean context. There are only 7 falsy values in Javascript:

  1. false
  2. 0
  3. -0 (negative 0)
  4. 0n (BigInt zero)
  5. "" (empty string)
  6. null
  7. undefined
  8. NaN (Not a Number)

Any other value is Truthy.

Truthy values

Everything else apart from the 7 falsy values is Truthy

Examples

  • "Hello" (non empty string).
  • 42 (any non zero number)
  • -42
  • 3.14
  • [] (empty array)
  • {} (empty object)
  • function() {}
