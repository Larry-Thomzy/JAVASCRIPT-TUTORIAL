Javascript Console 💻🎀

The console is a Built-up as javascript object that let you output messages, test values, and debug code.

It tells you what's happening inside your code

Common Console Methods

  1. console.log() → print general info or messages.
    ✅ Most commonly used for debugging and testing output
  2. console.error() → Displays error messages in red (indecating something went wrong)
    ✅ help you point out where bugs occur
  3. console.warn() → display warning (in yellow or orange)
    ✅ used when something isn't an error but still needs attention
  4. console.info() →Displays informational messages (lokks like log, but labelled as "info" in some browser).
  5. console.table() → Displays data in a neat table formal (super useful for arrays or objects),
  6. console.clear() → clears the console screen
  7. console.count() → counts how many times a label has been logged
  8. console.group()/console group() → Groups related logs together
    ✅ Helps helps organising console output when debugging
  9. console.times()/console.timeEnd → Measures how long a block of code takes to run
  10. console.assets() → logs an error only if a condition is false.
    ✅Useful for quick tests or validation
  11. console.trace() → Prints a stack trace (shows the path your code took to reach that point)
    ✅ Helps find which function or line triggered the call.
  12. console.dir → Displays an interractive list of an object's properties (especially for DOM elements).
  13. console.debug() → Works like log() but usually hidden unless you enable Verbose Logging in your Dev Tools
