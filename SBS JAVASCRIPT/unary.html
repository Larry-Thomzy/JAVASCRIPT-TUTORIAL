Unary Operators.

Unary Operators are operators that work on a single operands (one value or variable).
They perform operations like decrement, increment, type convertion, logical negation etc.

Common Unary Operators in Javascript.

  1. Increment (++)

    Increases a number by 1.

  2. Decrement (--)

    Decreases a number by 1.

  3. Unary Plus (+)

    Converts its operand into a number.

  4. Unary Negation

    Converts its operand into a number, then negates it.

  5. Logical NOT (!)

    Converts the operand to a boolean and inverts it.

  6. Bitwise NOT (~)

    Inverts all the bits of a number.
    Formula: ~n = -(n+1).

    It flips all the bits (0s becomes 1s, 1s becomes 0s).

  7. typeof

    Returns the type of a variable as a string.

  8. Delete

    Removes a property from and object.

  9. Void

    Evaluates an expression and returns undefined.
