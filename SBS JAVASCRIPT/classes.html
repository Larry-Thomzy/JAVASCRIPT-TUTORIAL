JavaScript Classes

Definition

A class in JavaScript is a blueprint for creating objects. It defines the properties (data) and methods (behavior) that the objects created from it will have.

Classes were introduced in ES6 and provide a cleaner, more structured syntax over JavaScript’s prototype-based inheritance.

Basic Syntax

            class Person {
                constructor(name, age) {
                    this.name = name;
                    this.age = age;
                }

                greet() {
                    return "Hello, my name is " + this.name;
                }
            }

            let user = new Person("John", 25);

Usefulness of Classes

  • Code organization: Groups related data and behavior together.
  • Reusability: Create multiple objects from the same blueprint.
  • Maintainability: Easier to read, debug, and extend.
  • Abstraction: Hides internal details and exposes only what is needed.
  • Supports OOP concepts: Encapsulation, inheritance, and polymorphism.

Constructor

The constructor is a special method that runs automatically when a new object is created from the class. 

        constructor(name, age) {
            this.name = name;
            this.age = age;
        }

Methods

Methods are functions defined inside a class. They describe what the object can do. 

        greet() {
            return "Hello";
        }

Inheritance

Classes can inherit properties and methods from other classes using the extends keyword. 

        class Student extends Person {
            constructor(name, age, course) {
                super(name, age);
                this.course = course;
            }
        }

Static Methods

Static methods belong to the class itself, not to instances of the class. 

        static info() {
            return "This is a Person class";
        }

Getters and Setters

Getters and setters allow controlled access to object properties. 

        get age() {
            return this._age;
        }

        set age(value) {
            if (value > 0) {
                this._age = value;
            }
        }

Important Notes

  • Classes are syntactic sugar over JavaScript prototypes.
  • Methods are stored on the prototype, not duplicated per object.
  • You must use new to create an instance of a class.

Summary

JavaScript classes provide a structured and readable way to create objects, making large applications easier to design, understand, and maintain.
