Javascript DOM mANIPULATION

The DOM (Document Object Model) represenyts your html file as a tree. Js let's you select elements from it.

Javascript can select, change, add or delete html element using the DOM.

  • Selecting Elements

    We need to grab before manipulating them.

    1. document.getElementById("id") → selects by id.
    2. document.getElementByClassName("Class") → selects all elements with that class.
    3. document.getElementByClassName("tag") → selects elements by tag name.
    4. document.querySelector("selector") → selects the first match (CSS selector).
    5. document.querySelectorAll("all") → selects all matches.

  • manipulating Elements

    Once selected, you can change their contents, style, or attributes.

    • elenemt.textContent → change inner text.
    • element.innerHTML → change inner HTML (can add tags).
    • element.style.property → change CSS styles
    • element.setAttributes("attr", "value") → change/set attributes
    • element.classlist.add/remove/toggle("class") → manage CSS classes

  • Events and Events Listeners

    Events are actions that happen in the browser (e.g click, hover, keypress)
    We use it to reacy when events happens

    Ways to add events

    1. Inline in HTML (not recommended)
    2. Assigned directly in Javascript
    3. Using addEventListener (best praticed)
