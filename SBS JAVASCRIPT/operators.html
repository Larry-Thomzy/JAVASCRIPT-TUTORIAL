Operators

Operators are symbols that perform actions on values (called operands)

numbers in an arithmetic operator is called OPERANDS

TYPES OF OPERATORS IN JS

  1. ARITHMETIC OPERATORS → Used for basic maths
  3. ASSIGNMENT OPERATORS (=) → Used to assign values
  4. COMPARISON OPERATORS → Used to compare values (returns true/false)
  5. LOGICAL OPERATORS → Used to combine conditions(AND, OR, NOT)
  6. INCREMENT / DECREMENT OPERATOR
