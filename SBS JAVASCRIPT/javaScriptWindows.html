🌐 Javascript Window & BOM

BOM

BOM (Browser Object Model) allows Javascript to interact with the browser (not the webpage itself - that's the DOM).

It represent browser features like:

  1. Window
  2. Navigator
  3. Location
  4. History
  5. Screen

Window Object

The window object is the global object in the browser. It's represent the browsers window.

All Javascript objects, functions and variables automatically become members of the window object.

Common Window Methods.

  1. alert() - Displays a message box.
  2. confirm() - Asks for confirmation (OK/CANCEL).
  3. prompt() - Input box.
  4. setTimeOut() - Runs code after delay (once).
  5. setInterval() - Runs code repeatedly at intervals.

Location Object (window.location)

It controls the url of the current page.

History Object (window.history).

Controls browser history (back/forward).

Navigator Object (window.navigator).

It gives info about the browser.
