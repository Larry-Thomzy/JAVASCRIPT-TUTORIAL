Asynchronous JavaScript

JavaScript is single-threaded (executes one thing at a time).

But sometimes tasks (like fetching data, waiting for a timer, or reading a file) take time.

If JS waited for them, everything else will freeze.

JS uses Asynchronous programming to run long task without blocking other code.

Why Async is useful in JavaScript

Async Js is super important in real world project because it helps your app remain fast, responsive, and efficient instead of freezing while waiting for task to finish loading.

Async allows other tasks (like UI Interactions)to keep running. Without Async, If one task is slow (like fetching data), everything else stops.

It improves performance - instead of waiting for one task to finish, multiple things can happen at the same time.

Summary - Users don't want apps that freeze while loading. Async makes apps smooth.

  1. setTimeout()

    Runs a function once after a given time (in miliseconds). Run once after delay.

  2. setInterval()

    Runs a function repeatedly after a given interval.

  3. Promises

    A promise represents a value that will be available now, later, or never.

    A promise in Js is like a contract. It says, "I promise to give you a result in the future". The result can be either success (resolved) or failure (rejected)

    • Three states:
      • Pending(waiting).
      • Fulfilled(resolved, success).
      • Rejected(Failed, error).

  4. Async/Await

    Async/Await is syntactic sugar used on top of promises.

    It makes Asynchronous code looks synchronous, making it easier to read and write

    The Async keyword declares a function as asynchronous. An Async function always returns a promise, even if you return a normal value

    The Await keyword can only be used inside an Async function. It pauses the execution until the promise is resolved or rejected
