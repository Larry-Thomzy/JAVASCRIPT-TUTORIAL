Ternary Operator.

The Ternary Operator is a short form of an if-else statement.

It is called ternary because it takes three operands:

condition ? expressionIfTrue: expressionIfFalse
  • condition → what you are checking (must be true or false).
  • expressionIfTrue → what runs if the condition is true.
  • expressionIfFalse → what runs if the condition is false.
