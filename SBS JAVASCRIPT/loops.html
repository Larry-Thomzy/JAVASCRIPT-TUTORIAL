LOOPS 🔃

A loop let you run the same block of code multiple times until a condition is met.

When you have to perform a task repeatedly until a condition is met, you will use a loop.

for (iterator; condition; iteration){ logic; }
for(let i = 0; i < count; i = i + 1){ console.log(i) }
  • Iterator - it is a variable that controls how the loop (iterates) goes through your logic
  • Condition - it tells the loop how many times it should iterate. When the condition becomes false, the loop stop.
  • Iteration - it will tell your loop what to do with the iterator after each run

Types Of Loops In javascript

  1. For loop - It is used when you know how many times you want to run the code
  2. While Loop - It runs as long as the condition is true
  3. do...while loop - It is similar to while loop, but it runs at least once, even if the condition is false
  4. for...of loop (for arrays, strings, etc)
  5. for...in loop
