Meta Programming

Meta programming refers to a number of ways a program can manipulate itself

  • modify object at run time
  • inspect object at run time
  • control object at run time
  • intercept running operations
  • modify function and classes
  • Dynamic code

Proxy Meta Programming

What is proxy

Aproxy is a wrapper arround another object (called the target) that lets you intercept and customize fundamental operations like:

  • Reading a property(get)
  • Writting a property(set)
  • checking if property exist(has)
  • Deleting a property(deleteProperty)
  • calling as function(apply)
  • constructing with new (construct)
  • And many more
