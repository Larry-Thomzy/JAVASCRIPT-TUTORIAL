OOP (Object-Oriented Programming).

OOP is a programming style where we organize code around objects (things) instead of just functions and logic.

Objects represent real-world entities with properties (data) and methods (actions).

Think of it like this:

  • Object = A car 🚗
  • Properties = color, model, year
  • Methods = drive(), stop()

Core OOP Concepts

  1. Class → Blueprints/Template for creating objects.
  2. Objects → An instance of a class
  3. Constructor → Special method to intialize objects.
  4. Encapsulation → Hiding details inside a class, exposing only what is necessary.
  5. Inheritance → A class can inherit properties/methods from another class.
  6. Polymorphism → Same method name but behaves differently in different classes.
