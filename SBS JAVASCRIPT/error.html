Error Handling

Error handling means detecting, catching, and responding to errors so your app doesn't crash or stop working.

Ways to handle errors in Javascript.

  1. try...catch.

    Code inside try runs

    If an errors happens, the catch block runs instead of crashing the program.

  2. Finally.

    Runs whether an error happens or not

  3. Throw (custom errors)

    You can create your own errors with throw.

  4. Error Handling in Promises

    When using promises, use .catch().

  5. Error Handling with Async/Await.

    Wrap Async code in try...catch.
