map() in javascript.

map() is na array method in javascript.

It creates a new array by applying a function to each element of the original array.

It doesn't change the original array.

📌 Key Points:

  1. Always returns a new array.
  2. The lenght of the new array = lenght of the orignal array.
  3. Commonly used for transforming data.

✅ Notes: map() is used when you want to transform each element of an array into a new form without touching the original array
