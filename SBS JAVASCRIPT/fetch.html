DOM & Browser APIs → Fetch API

The Fetch API is how we get (or send) data from/to a server.

It returns a promise, which means the data isn't available instantly - we have to wait for it to load.

fetch() - is a built-in javascript function used to make HTTP requests (GET, POST, PUT, DELETE etc.) from the browser.

It returns a promise that resolves to a response object

📌 Basic Syntax

fetch(url, options) .then(response => { }) .catch(error => { })
  • url → The API endpoint
  • options → An object (optional) that specifies the request method, header, body etc.
