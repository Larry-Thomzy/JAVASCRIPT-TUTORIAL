JavaScript Console 💻 🎀

The Console is a built-in JavaScript object that lets you output messages, test values, and debug code.

It tells you what's happening inside your code.

Common Console Methods

  1. console.log() → Prints general info or message.
    ✅ Most commonly used for debugging and testing output.
  2. console.error() → Displays error messages in red (indicating something went wrong).
    ✅ Helps you point out where bugs occur.
  3. console.warn() → Displays warning (in yellow or orange).
    ✅ Used when something isn't an error but still needs attention.
  4. console.info() → Displays informational messages (looks like log, but labelled as "info" in some browsers).
  5. console.table() → Displays data in a neat table format (super useful for arrays or objects).
  6. console.clear() → Clears the console screen.
  7. console.count() → Counts how many times a label has been logged.
  8. console.group()/console.groupEnd() → Groups related logs together.
    ✅ Helps organize console output when debugging complex scripts.
  9. console.time()/console.timeEnd() → Measures how long a block of code takes to run.
  10. console.assert() → Logs an error only if a condition is false.
    ✅ Useful for quick tests or validations.
  11. console.trace() → Prints a stack trace (shows the path your code took to reach that point).
    ✅ Helps find which function or line triggered the call.
  12. console.dir() → Displays an interactive list of an objects's properties (especially for DOM elements).
  13. console.debug() → Works like log() but usually hidden unless you enable Verbose Logging in your DevTools.
