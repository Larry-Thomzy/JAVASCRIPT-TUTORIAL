Switch

A Switch Statement is used to execute different code blocks based on the value of an expression. It is like an alternative to writing many if...else if statements.

📌 How it works

  1. JavaScript evaluate the expression.
  2. It checks each case.
  3. If it matches, it runs the code inside that case.
  4. The break statements stop the switch from continuing to the next case.
  5. If no match is found, The default case runs (optional).
