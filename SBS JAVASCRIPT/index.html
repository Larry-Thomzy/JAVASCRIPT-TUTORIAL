Index(Indices)

Every character in string has a position(index)

Indexing starts at zero(0) in Javascript

String

A string is a sequence of charaacters.
Each character has a position of an index.

Why do we use indexes

  • It's used to get specific characters
  • It's used to find where a letter or word is
  • It's used to check if something is there or not

Key String Method for Index?

  1. charAT()- returns the character at that position
  2. indexOf()- returns the index(position) of the first occurence
  3. lastIndexOf()- it returns the last occurence if the word appears more than once.
