📌 Object

Objects in JavaScript, are collections of related data.

Objects are collections of key-value pairs, where each key (also called a property) is a string and the value can be anything (string, number, array, function, and even another object).

  • An object is a stand-alone entity with properties and methods.
  • They help describe real world things.
