Logiical operators in Javascript

Logical operators are used to combine conditions.
There are 3 main ones:

  1. AND (&&)
    • Returns true if both conditions are true.
    • Example: "I will go out if the weather is sunny AND i have money"
  2. OR (||)
    • Returns true if at least one condition is true.
    • Example: "I will eat rice OR beans for dinner"
  3. NOT (!)
    • Reverses the result.
    • Example: "Iwill NOT watch tv today
