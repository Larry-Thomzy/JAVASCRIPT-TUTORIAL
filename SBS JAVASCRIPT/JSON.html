Working With Data

  1. JSON (JavaScript Object Notation)

    It is a light-weight format for storing and transferring data. It is mostly used to send data between a server and a web application.

    It is language-independent, but based on javascript object centers.

    Features Of JSON

    • Human-readable (Easy to understand).
    • light-weight and fast
    • It can be used with any programming language.
    • Often used in APIs and web services.

    Common Uses of JSON

    1. Sending data in APIs.
    2. Config files.
    3. Storing structured data (e.g user profiles).

  2. localStorage & sessionStorage

    • localStorage → Stores data permanently in the browser until manually cleared
    • sessionStorage → Stores data until the tab/browser is closed.

  3. Set & Map

    • Set → Stores unique values (No Duplicate).
    • Map → Stores key-values pairs (Like objects, but keys can be any type store).
