JavaSript Index (Indices)

Every character in a string has a position(index)

Indexing starts at zero(0) in javascript

Why do we use indexes

  • It is used to get specfic characters
  • It is used to find where a letter or word is
  • It is used to check if something is there or not

Key String Methods For Index

  1. charAt()- returns the character at that position
  2. indexOf()- returns the index(position) of the first occurence
  3. lastIndexOf()- It returns the last occurence of the word appears more than once
