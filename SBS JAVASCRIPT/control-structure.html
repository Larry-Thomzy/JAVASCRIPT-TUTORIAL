Control structure

Control structure helps us make decision and repeat actions in our code. Without them, our programs would just run line with no logic. There are 3 main types

  1. Conditional-Statement- if, else if, else, switch
  2. Loops - for, while, do....while
  3. Branching statement - break, continue, return

Conditional Statements- conditional statements allow our program to make decisions. It checks if something is true or false, then runs the right code

Real-Life example:"if it rains, i will take an umbrella, else, i won't

Flow of execution

  1. check the first condition (if) -if it's true,stop there and run that block.
  2. if it's not true,move to the next (else if) - if it's true, run it and stop
  3. if none match, finally run the else
