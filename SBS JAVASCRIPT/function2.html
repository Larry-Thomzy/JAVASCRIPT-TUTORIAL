JavaScript Function

A function is a re-usable block of code designed to perform a specific task.
Instead of repeating code, you can call the function whenever you need it.
Functions are designed to perform a particular task
Functions execute when they are called.

Types of Function

  1. Named Function → this is most common type.
    It has a name and can be called any where after its decleared.
  2. Anonymous Function → A function without a name, often used inside variables or other function.
  3. Function Expression → It is a function assigned to a variable (can be named or anonymous).
  4. Arrow function → A shorter and cleaner way to write functions.
  5. Immediately Invoked Function Expression (IIFE).
  6. Constructor Function → used to create objects
  7. Callback Function → A function passed into another function as an argument.
  8. Recursive Function →A fuction that calls itself.

Event

Event is something that happens on a webpage, like click, typing, scrolling, hovering, submitting a form, or when a page finishes

Event Name What It Does
onclick When something is clicked.
onmouseover When the mouse hovers over something
onchange When a form input changes
onkeydown When a key is pressed on a keyboard
onsubmit When a form is submitted
onload When the pages fnishes loading

Parameters and Argument

Parameters are the place holders or variables listed inside the function definition (They define what of data the function expects).

Arguments are the actual values to pass to the function when you call it.
