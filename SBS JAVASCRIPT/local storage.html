Local Storage

Local Storage is a way to store data in a web browser.

It allows web apps to save key-value pairs persistently (data stays even after refreshing or closing the browser).

Stored data has no expiration date (unlike session storage or cookies).

📌 Features:

  1. Size limit is about 5mb per domain (varies by browser).
  2. Data is specific to a domain (one site cannot access another site's data).
  3. Data remains manually cleared by developer or user.

setItem()

setItem() is a method used to store data in local storage as a key-value pair.

  • key → The name (string).
  • value → The data (string).
